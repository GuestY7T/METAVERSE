METAVERSE DEPLOYMENT READY

Canonical source of truth:
- METAVERSE-main/

Deploy target:
- Deploy the contents of METAVERSE-main/ as the site root.

Required files for deploy:
- index.html
- runtime-foundation.js
- service-worker.js
- manifest.json
- offline.html
- vendor/three.0.128.0.min.js

Repository root notes:
- The repo root keeps a redirect helper, but the app runtime lives in this folder.

Validation checklist:
- Site loads from index.html
- Service worker registers without console errors
- Offline fallback responds for navigations
- Asset paths are relative and same-origin

Notes:
- Future app changes should be made in METAVERSE-main/.
- Duplicate root runtime files were removed to avoid split app behavior.
