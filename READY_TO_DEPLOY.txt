METAVERSE DEPLOYMENT READY

Canonical source of truth:
- METAVERSE-main/

Deploy target:
- Deploy the contents of METAVERSE-main/ as your site root.

Required files for deploy:
- METAVERSE-main/index.html
- METAVERSE-main/runtime-foundation.js
- METAVERSE-main/service-worker.js
- METAVERSE-main/manifest.json
- METAVERSE-main/offline.html
- METAVERSE-main/vendor/three.0.128.0.min.js

Optional repository-root files:
- index.html (redirect helper only)
- README.md, FILES.md, CREDITS.md, LICENSE

Validation checklist:
- Site loads at /index.html
- Service worker registers without console errors
- Offline fallback returns offline.html for navigation requests
- App scripts load from same-origin relative paths

Notes:
- Root-level duplicate runtime assets were removed to prevent split runtime behavior.
- Use METAVERSE-main/ for all future app updates.
