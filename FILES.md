# Project Files Overview

- `METAVERSE-main/` contains the active app.
- root `index.html` is only a redirect helper.

- `METAVERSE-main/index.html`
- `METAVERSE-main/runtime-foundation.js`
- `METAVERSE-main/service-worker.js`
- `METAVERSE-main/manifest.json`

- `METAVERSE-main/vendor/three.0.128.0.min.js`
